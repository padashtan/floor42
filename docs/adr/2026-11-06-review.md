## Questions for the director

1. ADR-0056 (Docker for a mission): build the per-mission socket switch, or mark it Rejected before v1.0.0?
2. ADR-0063 (note 2026-11-11: native Linux runs since 1.17; only the Docker image still needs unsafe mode): real missions on Linux and in the Docker image need unsafe mode, so the launch quickstart cannot run a real mission there without it. Accept that and say it in the quickstart, or build a Linux confinement first?
3. ADR-0007 and ADR-0064: with IAM mode on, Keycloak is a second sign-in path. Write an ADR amendment to 0007, or leave 0064 as the record?
4. ADR-0064: confirm the IAM scope freeze for v1.0.0 (committee and auto-approved missions stay blocked in IAM mode; OpenFGA after v1.0.0).
5. `docs/docker.md` (outside this review) still says the sandbox "stays off in Docker" and does not mention `SANDBOX_REQUIRED`; update it with ADR-0063, or leave?
6. ADR-0004 and ADR-0006 cite local `spike/*` branches that the public repository will not hold: keep as history, or rewrite the evidence?
7. Records say "Office" and the director's decisions by role: keep as written for the launch (the index says so)?
